# 자동화

프롬프트 2개

## 담당자 알림 메일 템플릿 — 문의 유형별 (B3)

```
To: {{문의 유형}} 담당자 (프로그램 / 학생인건비 / 기타 → 센터 총괄)
Subject: [{{문의 유형}}] {{이름}}님의 문의가 접수되었습니다
Content: 문의자: {{이름}} / 이메일: {{이메일}} / 내용: {{문의 내용}}
※ {{ }}는 Google Forms 응답 변수. Make Router 경로별로 받는 사람만 바뀐다.
```

## 학생 접수 확인 메일 템플릿 (B3) ⭐

```
To: {{이메일}}
Subject: [에너지인력양성센터] 문의가 접수되었습니다
Content:
{{이름}}님 안녕하세요.
에너지인력양성센터에 보내주신 문의가 정상적으로 접수되었습니다.
■ 문의 유형: {{문의 유형}}
■ 문의 내용: {{문의 내용}}
담당자 확인 후 빠른 시일 내에 답변 드리겠습니다.
감사합니다.
```
